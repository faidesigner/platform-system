# Effects Guide

이 문서는 서비스에서 사용하는 그림자(Shadow) 토큰을 정의합니다.
실제 수치는 동일 폴더의 `effects.json` 파일을 참조하세요.

---

## 규칙

- 그림자 값은 임의 수치를 사용하지 않고 정의된 토큰만 사용합니다.
- 그림자는 요소의 시각적 계층(elevation)을 표현하는 데만 사용합니다.
- 장식 목적의 강한 그림자 사용을 지양합니다.
- 다크 모드에서도 동일 토큰을 사용합니다. 모드별로 별도 값을 지정하지 않습니다.

---

## Shadow 스케일

| 토큰 | 용도 |
| --- | --- |
| --shadow-XS | 미세한 구분이 필요한 요소 (인풋, 칩) |
| --shadow-S | 드롭다운, 툴팁 |
| --shadow-M | 카드, 패널 |
| --shadow-L | 플로팅 버튼, 강조 카드 |
| --shadow-XL | 모달, 사이드 시트 |
| --shadow-XXL | 전체 화면 오버레이 패널 |

---

## CSS 변수 패턴

```css
--shadow-{스케일}
/* 예시 */
box-shadow: var(--shadow-M);
box-shadow: var(--shadow-XL);
```
