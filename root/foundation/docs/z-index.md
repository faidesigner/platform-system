# Z-Index Guide

이 문서는 화면 위 요소의 쌓임 순서(z-index) 토큰을 정의합니다.
실제 수치는 동일 폴더의 `z-index.json` 파일을 참조하세요.

---

## 규칙

- 모든 z-index는 이 토큰만 사용합니다. 임의 수치 지정을 금지합니다.
- 컴포넌트 내부의 상대적 쌓임(예: 캐러셀 버튼)은 0~10 사이 로컬 값을 허용하되, 화면 레벨 요소는 반드시 토큰을 사용합니다.
- 100 단위 간격은 각 레벨 사이에 예외 케이스를 끼워 넣기 위한 여유입니다.

---

## 스케일

| 토큰 | 값 | 용도 |
| --- | ---: | --- |
| `--z-base` | 0 | 기본 흐름 |
| `--z-sticky-header` | 100 | 고정 헤더/내비게이션 |
| `--z-dropdown` | 200 | 드롭다운/셀렉트 |
| `--z-popover` | 300 | 팝오버, 캘린더 팝업 |
| `--z-tooltip` | 400 | 툴팁 |
| `--z-drawer` | 500 | 드로어/사이드 시트 |
| `--z-dialog` | 600 | 다이얼로그(모달) + 스크림 |
| `--z-toast` | 700 | 토스트 |
| `--z-loading-overlay` | 800 | 로딩 오버레이 |
| `--z-global-alert` | 900 | 전역 긴급 알림 |

---

## 마이그레이션 메모 ⚠️

- 기존 코드(NavigationBar, Header, Drawer 등)의 하드코딩 z-index를 이 스케일로 교체 필요 — 전수 조사 후 일괄 치환 권장
- `index.css`에 `@import './z-index.css';` 추가 필요 (codex 브랜치 작업과 충돌 방지를 위해 머지 후 진행)
