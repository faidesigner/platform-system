# Color Global Guide

이 문서는 서비스의 글로벌 컬러 팔레트(Primitive)를 정의합니다.
실제 수치는 동일 폴더의 `color-global.json` 파일을 참조하세요.

---

## 규칙

- 이 토큰은 직접 UI에 사용하지 않습니다.
- 반드시 `color-semantic.json` 또는 `color-brand.json`을 통해 참조합니다.
- 새로운 컬러가 필요한 경우, 기존 팔레트 내에서 먼저 찾습니다.
- 팔레트에 없는 값은 임의 추가하지 않고 시스템 관리자에게 요청합니다.

---

## 팔레트 구성

| 그룹 | 스케일 | 용도 |
| --- | --- | --- |
| red | 50 – 900 | 에러, 부정적 상태 |
| yellow | 50 – 900 | 경고, 주의 |
| orange | 50 – 900 | 경고, 강조 |
| green | 50 – 900 | 브랜드(FAI), 긍정 상태 |
| mint | 50 – 900 | 긍정, 성공 |
| blue | 50 – 900 | 정보, 링크 |
| indigo | 50 – 900 | 보조 강조 |
| purple | 50 – 900 | 보조 강조 |
| grape | 50 – 900 | 보조 강조 |
| gray | 30, 50, 100 – 900 | 중립, 텍스트, 배경 |
| bluegray | 30, 50, 100 – 900 | 중립, 보조 텍스트 |
| sand | 50 – 900 | 베이지 계열 서피스·면 배경 |
| skin | 50 – 900 | 사람 피부톤 표현 |
| brown | 단일값 | 특수 목적 |
| black | 단일값 | 순수 검정 |
| white | 단일값 | 순수 흰색 |

## CSS 변수 패턴

```css
--color-{group}-{scale}
/* 예시 */
--color-green-500
--color-gray-900
--color-white
```
