디자인팀 이선연, 김예슬이 함께 만드는 웹 플랫폼 기준 디자인 시스템입니다.

디자인 시스템이란 디지털 제품에서 기획자, 디자이너, 개발자가 공통으로 사용하는 언어 형태로서 디자인 원칙과 UX 패턴, UI 컴포넌트에서 나아가 자동화 등을 포함하는 시스템 라이브러리를 뜻합니다. 우리는 이를 통해 프로덕트 개발 시 효율적이고 일관적인 커뮤니케이션을 기대합니다.
