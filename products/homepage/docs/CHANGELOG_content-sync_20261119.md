## 구조 변경

**유튜브 재싱크가 영상을 빼지 않게 했습니다.** RSS 는 최신 15개만 주는데, 이전 스크립트는 그 창 밖으로 밀린 영상을 조용히 빼 버렸습니다. HOM-25 에서 2건이 빠졌고 `hideInLocales` 가 걸린 영상만 되살리는 안전망을 넣었지만, 이번 재싱크에서는 그 안전망에 해당하지 않는 6건(뚜쥬루·니세코 도입 사례, Super Swift, 베이커리 사용방법, 「VCO는 뭐가 다른가요」 ①②③)이 또 빠질 뻔했습니다. 이제는 직전 `youtube-showcase.json` 에 있던 영상을 전부 이어받고, 빼려면 `exclude` 에 적어야 합니다.

**Shorts 는 종류로 거릅니다.** `youtube-curation.json` 의 `excludeShorts: true` 가 RSS 의 `/shorts/` 링크를 보고 제외합니다. id 를 `exclude` 에 하나씩 적는 방식이면 채널에 Shorts 가 올라올 때마다 다시 들어오기 때문입니다. `manual` 에 직접 적은 Shorts 는 남습니다. RSS 파싱도 `scripts/lib/youtubeShowcase.mjs` 의 `parseRssEntries` 로 옮겨 테스트합니다.

**레터 새 글이 썸네일 없이 들어가지 않게 했습니다.** Stibee API 는 썸네일을 주지 않습니다. 새 레터는 가장 최근 기존 레터의 배너를 물려받습니다.

두 규칙 모두 스크립트 본문에서 `scripts/lib/youtubeShowcase.mjs`, `scripts/lib/stibeeLetters.mjs` 로 빼서 테스트로 고정했습니다(26건). 스크립트에는 네트워크와 파일 I/O 만 남았습니다.

**콘텐츠와 번역의 어긋남을 테스트로 잡습니다.**

- `config/mediaContent.test.ts`: 모든 레터에 ko·en·ja 제목 번역이 있는지, en·ja 제목에 한글이 섞이지 않았는지, 썸네일·링크가 있는지 봅니다. 번역이 없으면 화면은 깨지지 않고 한글 원문이 나가기 때문에 테스트 없이는 알 수 없습니다.
- `config/mediaNews.test.ts`: 뉴스는 `config/site.ts` 와 `messages/*` 가 인덱스로 묶여 있습니다. 항목 수, 날짜 내림차순, 썸네일 파일 존재, ko 제목 일치를 고정합니다.

## 주의사항

- 이어받은 영상의 제목·설명은 직전 값으로 고정됩니다. 유튜브에서 제목을 바꿨다면 `youtube-curation.json` 의 `manual` 에 적어야 반영됩니다.
- 32호 제목의 「베비에르」 영문 표기는 `Verviers` 입니다(오너 확인, 2026-11-19). 처음에는 표기를 몰라 en·ja 제목에서 상호를 뺐다가 같은 날 넣었습니다.
- 새 뉴스 3건의 en·ja 문구와 32~35호 제목 번역은 초벌입니다. en·ja 콘텐츠를 매번 검수하지는 않기로 해서(오너 결정, 2026-11-19) 이대로 운영합니다.
- 뚜쥬루 기사 썸네일은 매체 원본이 567×378 로 작습니다.
- ja 의 뚜쥬루 표기는 기존 번역에 맞춰 `TOUJOURS` 로 통일했습니다.
