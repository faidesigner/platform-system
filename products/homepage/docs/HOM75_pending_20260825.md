## 7. 재개 절차

### 완료된 것 (2026-08-25 이어서 작업분)

- **계획 Task 10 — 회귀 가드 `i18n/sheetDecisions.test.ts` 추가 완료** (`729163b`, develop 머지 `260ffdd`).
  `sheet-decisions.json`의 선언된 `codeValue`가 실제 `messages`와 어긋나면 실패한다. 이게 없으면 코드 값이 바뀐 뒤에도 선언이 계속 `DECIDED`를 반환해 **대조 도구가 실제 이격을 조용히 숨긴다** (`loadDecisionSet`은 `(key, locale)`만 조회 키로 쓰고 `codeValue`는 버리기 때문).
  가드 5종: locale 유효성 / key 존재 / codeValue 일치 / reason·decidedAt / (key, locale) 중복.
  flatten은 대조 도구와 **같은** `scripts/lib/sheetDiff.mjs`의 `flattenMessages`를 재사용한다 — 테스트가 자체 flatten을 두면 도구와 다른 키 경로를 보게 되어 가드가 통과해도 도구는 여전히 이격을 숨길 수 있다.
  4가지 오염 케이스(codeValue 불일치 / locale 오타 / 없는 key / reason 누락·중복)를 주입해 각각 FAIL 확인 후 원복했다.
- **HOM-75 카드 `❸ Fix Complete` 승격 + 조치 내역 기록.** `❹ QA 요청` 이상은 사용자가 수동으로 올린다.
