# SEO + jp→ja Implementation Plan

> **For agentic workers:** 각 Task를 subagent-driven-development로 구현. 정확한 카피/값은 spec(`docs/superpowers/specs/2026-07-01-seo-i18n-design.md`)에서 verbatim 사용.

**Goal:** Notion SEO 스펙 반영 + 일본어 로케일 `jp`→`ja` 일괄 변경, DEV 배포까지.

**Architecture:** 로케일별 SEO 값은 `config/site.ts`의 `seo` 맵(단일 소스), `app/[locale]/layout.tsx`의 `generateMetadata`가 소비. `<html lang>`은 이 Next 버전 문서 확인 후 정적 export 호환 방식으로 세팅.

**Tech Stack:** Next.js 16.2.7 (static export), next-intl, sharp(OG 이미지).

## Global Constraints
- 로케일: `ko`(기본,index) / `en`(noindex) / `ja`(noindex). `jp` 잔존 참조 0.
- 홈 `<title>`=검색제목, 서브페이지 템플릿 `%s | Fainders.AI`.
- 정확한 title/description/keywords/OG 문자열은 spec §3에서 verbatim.
- `pnpm lint` 실행 금지(사전 깨짐). 게이트 = `pnpm build && pnpm test`.
- `@fai/ui` 불변(이번 작업 대상 아님).
- EN/JA 완성 카피엔 `// TODO(marketing)` 주석.

## Task S1: jp → ja 로케일 리네임

**Files:** `i18n/routing.ts`, `messages/jp.json`→`messages/ja.json`(git mv), `app/robots.ts`, `components/layout/LanguageSwitcher.tsx`, `public/index.html`, `app/[locale]/layout.tsx`(주석).

- [ ] **Step 1:** `git mv products/homepage/messages/jp.json products/homepage/messages/ja.json`
- [ ] **Step 2:** `i18n/routing.ts` — `locales: ["ko", "en", "ja"]`
- [ ] **Step 3:** `app/robots.ts` — disallow 배열의 `"/jp/playground/"` → `"/ja/playground/"`
- [ ] **Step 4:** `components/layout/LanguageSwitcher.tsx` — `{ code: 'jp', label: 'JP' }` → `{ code: 'ja', label: 'JP' }` (표시 라벨 JP는 유지 가능; 코드만 ja)
  - ⚠️ **2026-08-31 정정:** 이 판단은 틀렸다. `JP`·`KR`은 ISO 3166-1 **국가코드**이고 스위처가 고르는 건 언어다. 라벨도 언어코드로 통일한다(`KO / EN / JA`). 이 문장이 남아 있는 동안 두 스위처가 `KO/EN/JP`·`KR/EN/JP`로 갈렸다. 현재 단일 출처는 `packages/ui/components/navigation/locales.ts`다.
- [ ] **Step 5:** `public/index.html` — 리다이렉트 맵 `{ ko:"ko", en:"en", ja:"jp", jp:"jp" }` → `{ ko:"ko", en:"en", ja:"ja", jp:"ja" }`; `hreflang="ja" href=".../jp/"` → `.../ja/`; 하단 링크 `/jp/` → `/ja/`; 주석 `/jp` → `/ja`
- [ ] **Step 6:** `app/[locale]/layout.tsx` 주석의 `/jp` → `/ja`
- [ ] **Step 7:** 잔존 확인: `grep -rn -e '"jp"' -e "'jp'" -e '/jp/' --include='*.ts' --include='*.tsx' --include='*.json' --include='*.html' products/homepage | grep -vE 'node_modules|/\.next/|/out/|base64|data:image'` → 코드/설정에 `jp` 0건
- [ ] **Step 8:** 게이트: `cd products/homepage && pnpm build && pnpm test` — `/ko /en /ja` 프리렌더, 테스트 통과
- [ ] **Step 9:** 커밋 `refactor(i18n): 일본어 로케일 코드 jp→ja (ISO 639-1)`

## Task S2: 로케일별 SEO 메타데이터 + html lang + hreflang + OG 이미지

**Files:** `config/site.ts`(seo 맵), `app/[locale]/layout.tsx`(generateMetadata), `app/layout.tsx`(ko 하드코딩 제거·구조 조정), OG 이미지 생성 스크립트/자산.

**Interfaces:**
- Produces: `seo` (Record<locale, {title,description,keywords,ogTitle,ogDescription}>), `getSeo(locale)` 헬퍼.

- [ ] **Step 1:** `config/site.ts`에 `seo` 맵 추가 — spec §3의 ko/en/ja title·description·keywords·ogTitle·ogDescription verbatim. en/ja 완성분엔 `// TODO(marketing)` 주석. 기존 `siteConfig.description`/`keywords`는 ko 폴백으로 유지하거나 seo.ko 참조로 정리.
- [ ] **Step 2:** OG 이미지 생성 — `public/images/customers/01-bakery-mannamil.jpg`를 sharp로 1200×630(cover crop)하여 `public/images/og/og-default.jpg` 생성. 일회성 스크립트 `scripts/make-og.mjs` 작성·실행(또는 수동), 결과 파일 커밋. 원본 비율에 맞춰 center crop.
- [ ] **Step 3: `<html lang>` — 먼저 Next 문서 확인.** `products/homepage/node_modules/next/dist/docs/` 에서 App Router root layout + dynamic `[locale]` 구조에서 `<html lang>` 세팅 방법을 확인(정적 export 호환). 확인 결과에 따라: (a) `<html lang={locale}>`를 `app/[locale]/layout.tsx`로 옮기고 root `app/layout.tsx`는 필수 요소만 유지, 또는 (b) 문서가 제시하는 이 버전의 권장 패턴 적용. 기존 GA `<GoogleAnalytics>`·JSON-LD·폰트 variable·globals.css import가 유실되지 않도록 주의.
- [ ] **Step 4:** `app/[locale]/layout.tsx` `generateMetadata` 확장 — 로케일별로:
  - `title: { default: seo[locale].title, template: "%s | Fainders.AI" }`
  - `description: seo[locale].description`
  - `keywords: seo[locale].keywords`
  - `openGraph: { type, locale(ko_KR/en_US/ja_JP), url, siteName:"Fainders.AI", title: ogTitle, description: ogDescription, images:[{url:"/images/og/og-default.jpg", width:1200, height:630}] }`
  - `twitter: { card:"summary_large_image", title, description, images }`
  - `alternates: { canonical: '/'+locale+'/', languages: { ko:'/ko/', en:'/en/', ja:'/ja/', 'x-default':'/ko/' } }`
  - `robots: { index: locale===defaultLocale, follow: true }`(기존 정책 계승)
- [ ] **Step 5:** `app/layout.tsx` 정리 — ko 하드코딩 `title`/`description`/`keywords`/`openGraph`/`twitter` 제거(로케일 레이어로 이동), `metadataBase`·`icons`·`manifest`·`robots` 기본·JSON-LD·`<GoogleAnalytics>`는 유지. JSON-LD의 description은 seo.ko.description으로 정렬.
- [ ] **Step 6:** 게이트 `pnpm build && pnpm test`. 빌드 산출 HTML에 로케일별 lang/title/og가 반영되는지 `out/` 스팟 확인(`grep`).
- [ ] **Step 7:** 커밋 `feat(seo): 로케일별 메타데이터·html lang·hreflang·OG 이미지`
